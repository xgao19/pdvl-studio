# PDVL Studio 0.2.0 — macOS Intel preview

Download **PDVL-Studio-0.2.0-macos-intel.dmg**, drag the application to Applications,
open it and enter your own Ollama API key. The DeepSeek Flash model is prefilled.
No separate Python, Node, Git or Codex installation is required.

- Native first-run API configuration and menu actions for settings, data and quit.
- Private data survives application replacement; normal ChatGPT/Codex login is untouched.
- Pinned Intel runtimes, dependency hashes, source-only build allowlist and bundled notices.
- Live validated chat → Codex execution → artifacts → evidence → manuscript citations,
  plus progress, foreground cancellation, session continuation and restart persistence.
- 49 Python tests and 4 Node UI tests passed.

This preview is **ad-hoc signed, not Apple Developer ID signed/notarized**. macOS may
require explicit approval in Privacy & Security after download. Do not disable system
security protections. Intel x86_64 only; minimum declared macOS 13, tested on 26.6.2.
Other models, advanced CLI tools and older macOS versions need separate validation.

API keys and research data are not included. API usage is billed/limited by the chosen
provider. Quit the application to stop both its local server and worker.

Verify the downloaded DMG against **SHA256SUMS**. The repository remains private;
release access follows its existing permissions.
